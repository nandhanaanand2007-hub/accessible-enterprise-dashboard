# Northstar — Accessible Enterprise Dashboard

A responsive multi-page dashboard built with semantic HTML5, CSS, and vanilla JavaScript.

## Pages
- `index.html` — overview, summary cards, activity table, and quick-add dialog
- `employees.html` — searchable employee directory and add-employee dialog
- `reports.html` — department performance report
- `settings.html` — accessible profile and notification form

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Accessibility features
- Semantic landmarks: `header`, `nav`, `main`, `aside`, `section`, `article`, and `footer`
- Skip-to-content link and visible keyboard focus
- Correct heading hierarchy and accessible table captions/column headers
- Explicit labels for every form control
- Native dialog with accessible name, keyboard handling, and validation
- Live status messages for form feedback
- Responsive layout, mobile navigation state, and reduced-motion support

## Before submitting
1. Extract this ZIP.
2. Create a **public** GitHub repository (for example `accessible-enterprise-dashboard`).
3. Upload all files and folders, keeping the folder structure unchanged.
4. In GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. After deployment, submit the GitHub Pages URL as the public link. The repository URL can also be submitted if the task specifically asks for a GitHub repository.

## Note
This is a front-end demonstration with sample data. Add a backend/API before using it with real employee information.
